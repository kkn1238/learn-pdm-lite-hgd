## EXPLAIN

### 1. 오늘 쓰는 데이터 — 다변수 센서 데이터

원본 강의(5일차 본 강의 덱 12~13장)의 정의를 그대로 쓴다.

| 용어 | 뜻 |
|---|---|
| 다변수 센서 데이터 | 진동·온도·압력처럼 여러 변수를 동시에 시간 순으로 기록한 것. 한 변수만으로는 놓치는 이상을 여러 변수를 함께 보면 잡아낸다 |
| 이상 패턴(anomaly) | 평소와 크게 다른 값이나 흐름 |
| 진동 (mm/s) | 베어링·회전체 마모, 정렬 불량을 감시. 갑작스러운 증가·추세적 상승이 전조 |
| 온도 (℃) | 마찰·과부하·윤활 부족을 감시. 서서히 오르는 흐름이 위험 신호 |
| 압력 (bar) | 유압·공압 계통 누출·막힘을 감시. 평상 범위 이탈 구간을 표시 |
