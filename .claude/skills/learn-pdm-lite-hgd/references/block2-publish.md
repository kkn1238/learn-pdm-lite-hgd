# Block 2: 공개 — GitHub Pages와 짝에게 보낼 메시지

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://docs.github.com/ko/pages/getting-started-with-github-pages/creating-a-github-pages-site
> ```

## EXPLAIN

### 1. 용어

| 용어 | 뜻 |
|---|---|
| GitHub 저장소 | 파일과 변경 기록을 올려 두는 온라인 폴더. 공개(public)로 두면 누구나 볼 수 있다 |
| GitHub Pages | 저장소의 `index.html`을 웹 주소(`https://<아이디>.github.io/<저장소>/`)로 보여 주는 기능 |
| 일회용 코드 로그인 | Claude Code가 보여 주는 8자리 코드를 브라우저(github.com/login/device)에 넣어 승인하는 방식. 비밀번호를 대화창에 적지 않는다 |
| 설치 한 줄 | `npx skills add <아이디>/<저장소> …` — 동료가 붙여 넣으면 같은 강의 스킬이 설치된다 |

### 2. 왜 공개까지 하는가

| 기준 | 내 컴퓨터에만 두기 | Pages로 공개 |
|---|---|---|
| 동료가 결과를 보는 방법 | 파일을 보내고 열어 달라고 부탁 | 주소 하나를 누르면 휴대폰에서도 열린다 |
| 결과 대조 | 어렵다 | 짝이 같은 수업을 듣고 자기 결과(추세 시작 시각)와 바로 비교한다 |

### 3. 공개 전 점검 — 보안 수칙

- 공개하는 것은 **가상 데이터와 그 결과뿐**이다. 원본 data/README: 가상 데이터는 보고서에 반드시 "가상 데이터(실습용)"로 표기한다.
- 회사 내부 자료·실제 설비 값·개인정보는 공개 저장소에 올리지 않는다.
- 비밀번호·토큰은 대화창에 붙여 넣지 않는다. 로그인은 브라우저에서 일회용 코드로만 한다.

## EXECUTE

사람이 직접 하는 일:

1. Claude Code가 일회용 코드를 보여 주면 브라우저에서 https://github.com/login/device 를 열고 코드를 넣는다.
2. "Authorize" 버튼을 눌러 승인한다. 끝나면 대화창에 "로그인 완료"라고 입력한다.

아래 프롬프트를 붙여 넣으라고 안내한다.

```
~/pdm-lite 의 결과를 GitHub Pages로 공개해 줘.
1. 공개 전 점검: index.html 에 "실습용 가상 데이터" 표기가 있는지, 폴더 안에 비밀번호·토큰·개인정보가 없는지 확인하고 결과를 보여 줘.
2. GitHub 로그인 상태를 확인해 줘. 안 되어 있으면 브라우저 로그인용 일회용 코드만 알려 주고 내가 "로그인 완료"라고 할 때까지 기다려 줘. 비밀번호는 묻지 마.
3. ~/pdm-lite 를 내 GitHub 에 공개 저장소 pdm-lite-<내 GitHub 아이디> 로 올려 줘.
   README.md 에 "센서 값은 실습용 가상 데이터 · 원본 keerhee/kma-auto-genai-3-1" 한 줄을 넣어 줘.
4. main 브랜치 루트로 GitHub Pages 를 켜고, 주소가 열리는지 확인해 줘 (처음에는 1~2분 걸릴 수 있어).
5. 짝에게 보낼 짧은 메시지를 만들어 줘: 대시보드 주소, 설치 한 줄
   npx skills add kkn1238/learn-pdm-lite-hgd --agent claude-code --global --yes
   수업을 부르는 이름 /learn-pdm-lite-hgd, 받는 사람이 할 일 세 줄.
```

### 확인할 것 (Phase B)

명령으로 직접 확인한다.

- `gh repo view pdm-lite-<아이디>`로 저장소가 public이고 `index.html`·`README.md`가 있다
- Pages 주소가 HTTP 200으로 열리고, 첫 화면 요약에 13:00이 보인다
- README와 대시보드에 "실습용 가상 데이터" 표기가 있다
- 공유 메시지에 대시보드 주소 · 설치 한 줄 · `/learn-pdm-lite-hgd` · 할 일 세 줄이 있다

Pages가 404면 아래 프롬프트를 준다.

```
Pages 주소가 404야. 저장소 Settings › Pages 의 소스가 main 브랜치 루트인지, index.html 이 루트에 있는지 확인하고 고쳐 줘.
```
